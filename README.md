# شيفتي — Shifti

تطبيق أندرويد بسيط لتسجيل أيام العمل والراحة وحساب الأجر بالساعة.

## بناء APK
كل Push إلى فرع `main` يشغّل GitHub Actions تلقائيًا. بعد نجاح البناء، افتح تبويب **Actions** ثم اختر آخر تشغيل وحمّل artifact باسم **shifti-debug-apk**.

التطبيق يحفظ البيانات محليًا على الجهاز باستخدام تخزين المتصفح داخل WebView.
